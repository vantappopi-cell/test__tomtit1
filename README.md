# Сайт для IT-кафедры

Учебный проект веб-сайта, разработанный для IT-кафедры.

## Стек технологий
* **HTML5** — разметка страницы и структура контента.
* **CSS3** (style.css, new.css) — стилизация элементов и оформление.
* **JavaScript** (script.js) — интерактивные элементы.

## Инструкция по запуску

Проект не требует серверной сборки. Запустить его можно двумя способами:

### Способ 1. Простое открытие
Просто откройте файл `index.html` в любом браузере двойным кликом мыши.

### Способ 2. Запуск через локальный сервер
Выполните в терминале (в корневой папке проекта) команду:
```bash
python3 -m http.server
```
После этого откройте браузер и перейдите по адресу: `http://localhost:8000`
